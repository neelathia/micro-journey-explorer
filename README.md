# Micro-Journey Explorer

A fictional public demonstration of a force-directed D3 knowledge graph for self-service documentation.

Explore a macro journey, micro-journey pages, and page sections. Filter content by five user intents: **Understand, Do, Verify, Troubleshoot, Learn more**.

This project is an educational prototype: all organization names, processes, steps, and coverage are illustrative. An intent mapping is not evidence of successful user testing.

## Publishing

Enable **Settings → Pages → Deploy from a branch → main → /(root)** to host the site. The homepage is `index.html`.

## Privacy

No analytics or identifying visitor tracking is installed. No proprietary documentation or internal links should be added to this public repository.

Uses D3.js via the public CDN.
